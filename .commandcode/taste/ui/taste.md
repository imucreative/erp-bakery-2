# UI

- Prefers widening the layout/columns so full values stay visible over truncating or abbreviating content to fit. Confidence: 0.5
- Wants a status/state column to be the leftmost column in a table. Confidence: 0.5
- Judges interactive controls by their visual affordance: clickable rows/headers should read as buttons (rounded corners + a background on hover) rather than as links (only a text-color change on hover). Confidence: 0.55
- Wants navigation to reflect the current route: the menu group containing the active screen — and any of its descendant pages (e.g. a `/new`, `/:id`, or `/:id/edit` child of a list route) — should automatically stay expanded and the corresponding item(s) highlighted. Confidence: 0.6
- Treats the upstream TailAdmin demo/repo as the exact design source of truth: when the project deviates from the demo, wants the demo's implementation ported verbatim (structure, markup, spacing, classes) instead of approximated. Functional extras the project needs (e.g. collapsible/expandable menu groups) may be kept, but only if their visual result still matches the demo. Confidence: 0.7
- Wants compact spacing around navigation group labels: labels as plain text with no padding/box chrome, and no leftover vertical gap between group labels when groups are collapsed. Confidence: 0.6
- Wants quantity fields always paired with a UOM/unit column, and applied consistently across every surface of a feature — all similar report tables (inventory, sales top products, production) and their CSV exports — not just the screen he happened to be looking at. Confidence: 0.6
- Prefers base UI components built on headless primitives from the project's existing library (reka-ui — e.g. `CheckboxRoot`/`CheckboxIndicator`, `Dialog`, `Select`, `Switch`, `Label`) so accessibility and state handling come from the library ("biar lebih bagus"), while keeping the component's public API unchanged; expects the whole base-component set to be audited and migrated wherever Reka offers an equivalent ("kalau bisa menggunakan reka-ui, gunakan saja"), not just the one component being touched — but migrated incrementally, one component at a time ("nanti kita ubah 1 per 1"). Confidence: 0.8
- Prefers UI copy and menu/item labels written in English rather than Indonesian (renames leftover Indonesian menu names to English for consistency), even though conversation itself is in Indonesian. Confidence: 0.55
