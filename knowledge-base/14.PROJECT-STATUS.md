## 1. ARSITEKTUR AKTUAL (per kode)

### Backend
- **Framework:** NestJS + TypeScript (HTTP adapter: **Fastify**)
- **Database:** PostgreSQL (port **5435**), akses via **raw SQL** menggunakan `pg` Pool — **tanpa ORM**
- **Migrasi:** `node-pg-migrate` (folder `backend/migrations/`, tersedia sampai **075**: 071 dashboard/reports permissions, 072 2FA, 073 profile, 074 password reset tokens, 075 revoke system-admin permissions from company roles)
- **Pola:** Clean Architecture ala Hexagonal:
  `Domains` (entity + abstract repository) → `Applications/use_case` (orchestration) →
  `Infrastructures` (repository Postgres, security, DI module) → `Interfaces/http` (controller, guard, decorator, DTO)
- **Auth:** JWT access/refresh; Profile, change password, forgot/reset password dan 2FA tersedia. `ConsoleMailSender` hanya log, bukan pengiriman email produksi.
- **Otorisasi:** Permission-based RBAC; route platform `@SuperAdminOnly()` memerlukan Super Admin dan 2FA aktif. Platform bukan bypass konteks company untuk operasi tenant.
- **SaaS:** data operasional per Company; assignment outlet melalui `user_outlets`. SUPER_ADMIN di-seed dan menggunakan Platform Console terpisah; isolasi seluruh modul tetap perlu QA.
- **Dokumentasi API:** Swagger di `/api/docs`
- **Test:** Jest. **Lint:** ESLint (belum rapi se-project; gate otoritatif = `tsc`).

### Frontend
- **Stack:** **Vue 3 + Vite + Tailwind CSS v4** berbasis template **TailAdmin**, folder `frontend-tailadmin/`
- **Type check / build:** `vue-tsc --build` + `vite build`
- **Auth & RBAC:** login/signup/register company; **sidebar & aksi di-gate per permission**
- **Pola:** service layer (`src/services/*`) → views (`src/views/*`) + komponen fitur (`src/components/*`); detail dokumen dilengkapi timeline/comments/attachments
- **UI Foundation (reusable):** `src/components/ui/` — `BaseButton`, `BaseFormField`, `BaseInput`, `BaseTextarea`, `BaseSelect`, `BaseToggle`, `BaseTable` (+ `BaseTableRow`/`BaseTableHead`/`BaseTableCell`, slot footer), `BaseTablePagination`, `SearchInput`, `EntityCombobox` (autocomplete), `BaseFileButton`, `BaseAlert` dan `BaseModal` sudah tersedia pada HEAD audit. Aturan pakai kanonik di doc `48.tailadmin-frontend-backlog.md` §2.
