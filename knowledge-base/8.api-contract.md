# API CONTRACT DOCUMENT

# Bakery ERP System

Version: 1.3.0

Base URL:

/api/v1

Authentication:

Bearer Token (JWT)

Content-Type:

application/json

---

# API RESPONSE STANDARD

## Success Response

HTTP Status: 200

```json
{
  "success": true,
  "message": "Success",
  "data": {}
}
```

---

## Error Response

HTTP Status: 400

```json
{
  "success": false,
  "message": "Validation Error",
  "errors": [
    {
      "field": "sku",
      "message": "SKU already exists"
    }
  ]
}
```

---

# AUTH MODULE

## Login

POST /auth/login

Request:

```json
{
  "email": "owner@mail.com",
  "password": "password"
}
```

Response:

```json
{
  "success": true,
  "message": "Login Success",
  "data": {
    "accessToken": "jwt-token",
    "refreshToken": "refresh-token",
    "user": {}
  }
}
```

---

## Logout

POST /auth/logout

---

GET /auth/profile
