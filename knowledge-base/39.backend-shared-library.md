# 39. Backend Shared Library

This document outlines the standard abstract base classes, generic repository interfaces, and shared response models in the NestJS backend workspace to maximize code reuse and maintain strict repository pattern boundaries.

---

## 1. Base Entity Structure

All transactional DB entities must inherit from a common base definition containing standard audit properties:

```typescript
export abstract class BaseEntity {
  id: string; // UUID
  createdAt: Date;
  updatedAt: Date;
  approvedAt?: Date;
  deletedAt?: Date;
  createdBy: string;
  updatedBy?: string;
  approvedBy?: string;
  deletedBy?: string;
}
```

---

## 2. Generic Base Repository (Prisma Wrapper)

To reduce duplicate query boilerplate, standard repositories must inherit from a common generic class:

```typescript
import { PrismaClient } from '@prisma/client';

export abstract class BaseRepository<T, CreateDto, UpdateDto> {
  constructor(
    protected readonly prisma: PrismaClient,
    protected readonly modelName: string
  ) {}

  async findById(id: string): Promise<T | null> {
    return this.prisma[this.modelName].findFirst({
      where: { id, deletedAt: null }
    });
  }

  async create(data: CreateDto, userId: string): Promise<T> {
    return this.prisma[this.modelName].create({
      data: {
        ...data,
        createdBy: userId
      }
    });
  }

  async update(id: string, data: UpdateDto, userId: string): Promise<T> {
    return this.prisma[this.modelName].update({
      where: { id },
      data: {
        ...data,
        updatedBy: userId
      }
    });
  }

  async softDelete(id: string, userId: string): Promise<T> {
    return this.prisma[this.modelName].update({
      where: { id },
      data: {
        deletedAt: new Date(),
        deletedBy: userId
      }
    });
  }
}
```

## 3. Base Service & Controller Patterns

Services and Controllers orchestrate flow and map request payloads.

### Base Service:
- Orchestrates NestJS transactions (`this.prisma.$transaction`).
- Enforces strict validation checks (verifying relations exist).
- Dispatches Domain Events (e.g. `EventEmitterModule`).

### Base Controller:
- Maps request parameter constraints.
- Declares standard swagger parameters (`@ApiQuery()`, `@ApiResponse()`).
- Binds Guards (`JwtAuthGuard`, `PermissionGuard`).

## 4. ApiResponse & Global Exception Filters

To enforce uniform JSON output:

```typescript
export class ApiResponse<T> {
  success: boolean;
  data?: T;
  message?: string;
  meta?: {
    page: number;
    limit: number;
    total: number;
  };

  static success<T>(data: T, meta?: any): ApiResponse<T> {
    return { success: true, data, meta };
  }

  static error(message: string): ApiResponse<null> {
    return { success: false, message };
  }
}
```

### Global Exception Filter:
- Catches all exceptions.
- Converts Prisma specific codes (e.g. `P2002` for unique constraint fail) to `400 Bad Request` or `409 Conflict` HTTP codes.
- Returns standardized `ApiResponse.error` payloads to the client.
