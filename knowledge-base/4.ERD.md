# 1. Master Data Module

---

# Table: outlets

Stores all business outlets.

| Field      | Type         | Constraint   |
| ---------- | ------------ | ------------ |
| id         | uuid         | PK           |
| code       | varchar(20)  | UNIQUE       |
| name       | varchar(100) | NOT NULL     |
| address    | text         | NULL         |
| phone      | varchar(30)  | NULL         |
| is_active  | boolean      | DEFAULT TRUE |
| created_at | timestamp    |              |
| updated_at | timestamp    |              |

Relationship:

* Outlet has many Warehouses.
* Outlet has many Sales.

---

# Table: warehouses

Stores warehouse information.

| Field              | Type      |
| ------------------ | --------- |
| id                 | uuid      |
| outlet_id          | uuid FK   |
| code               | varchar   |
| name               | varchar   |
| type               | enum      |
| is_production_site | boolean   |
| is_active          | boolean   |
| created_at         | timestamp |
| updated_at         | timestamp |

Warehouse Type:

* CENTRAL
* OUTLET

Relationship:

* Warehouse belongs to Outlet.
* Warehouse has many Inventory Batches.
* Warehouse has many Production Orders.

Business Rules:

* Every outlet has at least one warehouse.
* Only warehouse marked as production site can execute production.

| Field            | Type           | Constraint   |
| ---------------- | -------------- | ------------ |
| id               | uuid           | PK           |
| sku              | varchar UNIQUE | NOT NULL     |
| barcode          | varchar        | NULL         |
| name             | varchar        | NOT NULL     |
| product_group_id | uuid FK        | NOT NULL     |
| category_id      | uuid FK        | NOT NULL     |
| unit_id          | uuid FK        | NOT NULL     |

| is_active        | boolean        | DEFAULT TRUE |

| updated_at       | timestamp      |              |

Product Type:

* RAW_MATERIAL
* FINISHED_GOODS
* SEMI_FINISHED
* PACKAGING

Business Rules:

* SKU must be unique.
* Batch tracking enabled by default.
* Product must reference a valid Product Group, Category, Unit, and Supplier.
* Selected Category must belong to the selected Product Group.

# 3. Inventory Module

---

# Table: inventory_batches

Stores stock by batch.

| Field         | Type      |
| ------------- | --------- |
| id            | uuid      |
| warehouse_id  | uuid FK   |
| product_id    | uuid FK   |
| batch_number  | varchar   |
| expired_date  | date      |
| qty_available | decimal   |
| received_date | date      |
| status        | enum      |
| created_at    | timestamp |

Batch Status:

* ACTIVE
* EXPIRED
* CONSUMED
* QUARANTINE

Indexes:

* warehouse_id
* product_id
* expired_date

Business Rules:

* FEFO must use nearest expiry date.
* Expired batch cannot be used.

---

| Field          | Type      |

| reference_id   | uuid      |
| notes          | text      |

Movement Types:

* PURCHASE
* PRODUCTION_CONSUME
* PRODUCTION_RESULT
* SALE
* RETURN
* TRANSFER_OUT
* TRANSFER_IN
* ADJUSTMENT
* OPNAME

Business Rules:
