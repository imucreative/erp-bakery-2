## 2. Scope & Deliverables

### 2.1 Dashboard Module

#### Owner Dashboard
**Endpoint:** `GET /dashboard/owner`
**Permission:** `dashboard.read`

**Metrik (KPI Cards):**
1. **Revenue Today** — Total pendapatan hari ini (Asia/Jakarta timezone)
   - Sumber: `sales_orders.grand_total` WHERE `status = 'PAID'` AND `paid_at` today
   - Format: Currency (Rp)
   
2. **Total Sales Today** — Jumlah transaksi hari ini
   - Sumber: COUNT(`sales_orders.id`) WHERE `status = 'PAID'` AND `paid_at` today
   - Format: Number
   
3. **Low Stock** — Produk dengan stok menipis
   - Sumber: Reuse `InventoryDashboardSummary.lowStockCount`
   - Format: Number + link ke inventory list
   
4. **Expired Product** — Produk kedaluwarsa
   - Sumber: Reuse `InventoryDashboardSummary.expiredCount`
   - Format: Number + link ke inventory list

**Additional Widgets:**
5. **Sales Trend (7 days)** — Grafik line penjualan 7 hari terakhir
   - Sumber: GROUP BY DATE(`paid_at`) SUM(`grand_total`) WHERE `status = 'PAID'`
   - Format: Line chart (date, revenue)
   
6. **Expiring Soon (≤30 days)** — Daftar batch akan kedaluwarsa
   - Sumber: Reuse `InventoryDashboardSummary.expiringSoonCount` + batch list
   - Format: Table (product, batch, expiry date, qty)
   
7. **Top Selling Products (7 days)** — Produk terlaris
   - Sumber: GROUP BY `product_id` SUM(`qty`) FROM `sales_order_items` JOIN `sales_orders` WHERE `status = 'PAID'` AND `paid_at` >= 7 days ago
   - Format: Table (product name, qty sold, revenue)

#### Outlet Dashboard
**Endpoint:** `GET /dashboard/outlet?outletId={id}`
**Permission:** `dashboard.read`

**Metrik (scoped ke outlet):**
1. **Today's Sales** — Jumlah transaksi outlet hari ini
2. **Low Stock** — Produk menipis di outlet ini
3. **Pending Requests** — (future: replenishment requests, currently placeholder)

**Note:** Outlet dashboard adalah varian ringkas dari Owner, scoped ke satu outlet.

**Key Queries:**
```sql
-- Revenue today
SELECT COALESCE(SUM(grand_total), 0) as revenue
FROM sales_orders
WHERE company_id = $1
  AND status = 'PAID'
  AND DATE(paid_at AT TIME ZONE 'Asia/Jakarta') = CURRENT_DATE;

-- Sales trend (7 days)
SELECT 
  DATE(paid_at AT TIME ZONE 'Asia/Jakarta') as date,
  SUM(grand_total) as revenue,
  COUNT(*) as order_count
FROM sales_orders
WHERE company_id = $1
  AND status = 'PAID'
  AND paid_at >= NOW() - INTERVAL '7 days'
GROUP BY DATE(paid_at AT TIME ZONE 'Asia/Jakarta')
ORDER BY date;

-- Top selling products (7 days)
SELECT 
  soi.product_id,
  soi.product_name_snapshot,
  SUM(soi.qty) as total_qty,
  SUM(soi.line_total) as total_revenue
FROM sales_order_items soi
JOIN sales_orders so ON so.id = soi.sales_order_id
WHERE so.company_id = $1
  AND so.status = 'PAID'
  AND so.paid_at >= NOW() - INTERVAL '7 days'
GROUP BY soi.product_id, soi.product_name_snapshot
ORDER BY total_qty DESC
LIMIT 10;
```

**Key Queries:**
```sql
-- Sales report summary
SELECT 
  COUNT(*) as total_orders,
  COALESCE(SUM(grand_total), 0) as total_revenue,
  COALESCE(AVG(grand_total), 0) as average_order_value,
  COALESCE(SUM(item_count), 0) as total_items_sold
FROM sales_orders
WHERE company_id = $1
  AND status = $2
  AND paid_at BETWEEN $3 AND $4
  AND ($5 IS NULL OR outlet_id = $5);

-- Inventory report (stock on hand per product)
SELECT 
  p.id as product_id,
  p.name as product_name,
  p.sku,
  COALESCE(SUM(ib.qty_available), 0) as total_qty,
  COUNT(DISTINCT ib.id) as batch_count,
  MIN(ib.expired_date) as earliest_expiry
FROM products p
LEFT JOIN inventory_batches ib ON ib.product_id = p.id AND ib.status = 'ACTIVE'
WHERE p.company_id = $1
  AND ($2 IS NULL OR p.id = $2)
  AND ($3 IS NULL OR ib.outlet_id = $3)
GROUP BY p.id, p.name, p.sku;
```

## 6. Technical Decisions

### 6.1 Timezone Handling
- Semua timestamp disimpan di UTC (database default)
- Dashboard "today" menggunakan Asia/Jakarta timezone
- Query: `DATE(paid_at AT TIME ZONE 'Asia/Jakarta') = CURRENT_DATE`

### 6.2 Chart Library
- **Opsi 1:** Chart.js + vue-chartjs (popular, flexible)
- **Opsi 2:** ApexCharts (built-in themes, easier)
- **Rekomendasi:** ApexCharts (sudah ada di TailAdmin template)

### 6.3 Export Format
- **CSV:** Native generation (no dependency) — string concatenation + Blob download
- **PDF:** jsPDF + autoTable plugin (client-side) atau Puppeteer (server-side)
- **Rekomendasi:** Client-side jsPDF untuk simplicity

### 6.4 Caching Strategy
- Dashboard data: no cache (real-time)
- Reports: no cache (filtered on-demand)
- Future: Redis cache untuk heavy queries (top products, trends)

### 6.5 Performance Considerations
- Sales trend query: indexed on `(company_id, status, paid_at)`
- Top products query: indexed on `(sales_order_id)` di `sales_order_items`
- Inventory report: indexed on `(product_id, outlet_id, status)` di `inventory_batches`
- Future: materialized views untuk dashboard metrics (refresh every 5 min)
