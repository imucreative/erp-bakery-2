## v1.3.0

### Added

- **Product Group Master Data Module**:
  - Introduced the new master classification level above Product Categories.
  - Defined business properties: Code (unique, uppercase), Name (unique), Description, Status (isActive), and Soft Delete (`deletedAt`).
- **Product Group API Contracts**:
  - GET `/product-groups` (paginated list, with filtering and search)
  - GET `/product-groups/lookup` (returns simplified list of active groups)
  - GET `/product-groups/:id` (returns group details)
  - POST `/product-groups` (creates a new group, requires unique code and name)
  - PUT `/product-groups/:id` (updates name/description/isActive)
  - DELETE `/product-groups/:id` (soft delete validation, checks for active references)
- **Product Group User Stories**:
  - Added stories PG-001 (Create Product Group), PG-002 (Update Product Group), and PG-003 (Deactivate/Delete Product Group).
- **Product Group Wireframe Screens**:
  - Added wireframe layouts and routes for `/masters/product-groups` (List) and `/masters/product-groups/create` (Form).

### Updated
