## 2. Directory Layout Standard

All frontend business features must live inside `/frontend/src/app/(dashboard)/<feature>` following this structure:

```
frontend/src/app/(dashboard)/<feature>/
├── page.tsx                    # Main Page container & business logic coordinator
└── components/                 # Isolated view components (no Shadcn direct imports)
    ├── index.ts                # Component exports entrypoint
    ├── <feature>-columns.tsx   # Table headers & row definitions
    ├── <feature>-delete-dialog.tsx # Delete confirmation modal
    ├── <feature>-filter-bar.tsx # Search input & filter dropdowns
    ├── <feature>-form-dialog.tsx # Form creation/edit overlay dialog
    ├── <feature>-header.tsx     # Page title, subtitle, & main action buttons
    └── <feature>-table.tsx      # Table grid wrapper
```
