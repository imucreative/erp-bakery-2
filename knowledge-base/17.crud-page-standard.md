# Definition of Done

A CRUD page is considered complete only when every checklist item above has been satisfied.

---

Before implementing this task:

Review the entire Bakery ERP codebase.

Compare every CRUD page against the ERP UI Foundation.

Identify inconsistencies.

Apply the minimum changes required to make every page conform to the shared UI standard.

Do not introduce new abstractions unless they are reusable across the entire application.

If a shared component already exists, it must be reused instead of creating a new implementation.

If you discover duplicated layouts or duplicated UI code, refactor them to use the shared component library.
