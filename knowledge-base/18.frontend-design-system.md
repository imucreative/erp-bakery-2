## 1. Visual Token Definitions

All UI components must strictly use the Tailwind CSS class tokens listed below.

### A. Spacing & Padding
- **Page Bottom Margin**: `mb-8` (applied to page headers)
- **Section Bottom Margin**: `mb-6` (pushed between toolbars, notifications, and card layouts)
- **Card Padding**: `p-5` (applied to filters, search controls, and content containers)
- **Table Cell Padding**: `px-6 py-4` (applied to table headers and body cells)
- **Dialog Width (Default)**: `sm:max-w-md` (modal sizes)
- **Dialog Width (Wide)**: `sm:max-w-2xl` (large modal lists/forms)

### B. Border Radius
- **Cards & Card Wrappers**: `rounded-2xl`
- **Badges & Dot Indicators**: `rounded-full`
- **Inputs (Textarea, Select, Input)**: `rounded-xl`
- **Buttons (ERPButton)**: `rounded-lg`
- **Notifications & Toast banners**: `rounded-xl`

### C. Typography
- **Page Title**: `text-3xl font-extrabold tracking-tight text-slate-900 dark:text-white`
- **Page Description**: `text-sm text-slate-500 dark:text-slate-400`
- **Section Title**: `text-lg font-bold text-slate-800 dark:text-slate-200`
- **Table Header**: `text-xs font-semibold text-slate-600 dark:text-slate-400 uppercase tracking-wider`
- **Table Cell (Default)**: `text-sm text-slate-600 dark:text-slate-300`
- **Table Cell (Bold)**: `text-sm font-semibold text-slate-900 dark:text-slate-200`
- **Form Label**: `text-sm font-medium text-slate-700 dark:text-slate-300`
- **Validation Error Text**: `text-xs text-rose-600 dark:text-rose-400`

## 2. Table Component Standardization

Tables must strictly use the unified layout classes to keep alignments consistent across all list views:

```typescript
export const tableTokens = {
  wrapper: 'min-w-full divide-y divide-slate-200 dark:divide-slate-800',
  thead: 'bg-slate-50/80 dark:bg-slate-900/80',
  tbody: 'divide-y divide-slate-100 dark:divide-slate-800',
  rowHover: 'hover:bg-slate-50/50 dark:hover:bg-slate-900/20 transition-colors',
  cell: 'px-6 py-4',
  cellAction: 'px-6 py-4 whitespace-nowrap text-right',
};
```

---

## 3. Dark Mode Compliance

Every element must implement a dark variant to support theme switching:
- **Backgrounds**: Use `bg-slate-900`, `bg-slate-950/5`, or similar dark backgrounds for cards/sections.
- **Borders**: All border dividers must use a dark variant like `dark:border-slate-800`.
- **Text Color**: Muted text must use `dark:text-slate-400` and default body/title text must use `dark:text-slate-200` or `dark:text-white`.

---

## 4. Mobile Responsiveness Guidelines

- **Table Horizontal Scrolling**: All data tables must wrap inside a scrollable container (`overflow-x-auto`) to avoid breaking mobile columns.
- **Grids & Flex Spacing**: Grid layouts in form dialogs must use responsive breakpoints (e.g. `grid grid-cols-1 sm:grid-cols-2 gap-4`).
- **Flexible Toolbars**: Search inputs and status filters must wrap on small viewports using flex-wrap layout parameters (`flex flex-col sm:flex-row gap-4`).
