# USER STORIES DOCUMENT

# Bakery ERP System

Version: 1.3.0

Methodology: Agile Scrum

---

# EPIC: AUTHENTICATION

## AUTH-001

Priority: Must Have

Story Point: 3

As a user,

I want to login into the system,

So that I can access system features based on my permissions.

Acceptance Criteria:

* User can login using email.
* User can login using password.
* Invalid credentials should be rejected.
* Inactive user cannot login.
* JWT token must be generated.

---

## AUTH-002

Priority: Must Have

Story Point: 2

As a user,

I want to logout,

So that my session is securely terminated.

Acceptance Criteria:

* User can logout.
* JWT token becomes invalid.

---

## AUTH-003

Priority: Must Have

Story Point: 5

As an owner,

I want to manage user roles and permissions,

So that system access can be controlled.

Acceptance Criteria:

* Create role.
* Update role.
* Assign permissions.
* Remove permissions.

# EPIC: PRODUCT GROUP MANAGEMENT

## PRODUCT-GROUP-001

Priority: Must Have

Story Point: 3

As an owner,

I want to create a Product Group,

So that categories and products can be classified.

Acceptance Criteria:

* Product Group code must be unique and automatically converted to uppercase.
* Product Group name must be unique (case-insensitive).
* Product Group status defaults to active.

---

## PRODUCT-GROUP-002

Priority: Must Have

Story Point: 2

As an owner,

I want to update Product Group details,

So that data remains accurate.

Acceptance Criteria:

* Product Group name and description can be updated.
* Code is immutable.
* Status can be toggled (isActive).
* Audit log is generated for changes.

---

## PRODUCT-GROUP-003

Priority: Must Have

Story Point: 2

As an owner,

I want to delete Product Groups,

So that obsolete classifications are removed.

Acceptance Criteria:

* Soft delete only.
* Cannot delete if referenced by active categories or active products.
* Audit log is generated.

# EPIC: PRODUCT MANAGEMENT

## PRODUCT-001

Priority: Must Have

Story Point: 5

As an owner,

I want to create products,

So that products can be used in inventory and sales transactions.

Acceptance Criteria:

* SKU must be unique.
* Product type is mandatory.
* Shelf life is mandatory.
* Batch tracking enabled by default.
* Product must belong to a valid Product Group, Category, UOM, and Supplier.
* Selected Category must belong to the selected Product Group.

## PRODUCT-003
