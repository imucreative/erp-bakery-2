## [10:15] Melengkapi 3 permintaan UI frontend-tailadmin + jeda QA otomatis — project-manager (orkestrator)

User memberi 3 permintaan pelengkap untuk `frontend-tailadmin/` plus 2 instruksi
proses: catat ke knowledge-base, dan hentikan sementara E2E/QA otomatis untuk
menghemat token. Saya (PM) kali ini mengeksekusi langsung karena scope-nya kecil,
terlokalisir di layer view, dan tidak menyentuh backend/business logic — bukan
pekerjaan yang perlu didelegasikan penuh ke frontend-dev.

Yang dikerjakan:

1. **Jeda hook QA otomatis.** File `.kiro/hooks/qa-after-dev.json` di-rename menjadi
   `.kiro/hooks/qa-after-dev.json.disabled` supaya loader hook Kiro tidak lagi
   memicunya tiap akhir sesi. Reversibel: cukup rename balik untuk mengaktifkan.
   Verifikasi jadi on-demand (manual) sementara ini.

2. **Pertanyaan #1 (fitur Outlet).** Dijawab, tanpa perubahan kode: backend Outlet
   SUDAH ada (CRUD penuh, permission `outlet.read`/`outlet.manage`). Di frontend
   baru hanya ada `outlet.service.ts` READ-ONLY yang dipakai dropdown Users.
   Halaman CRUD Outlet belum dibangun semata karena belum masuk urutan pilihan
   user — bukan bug. Backlog-nya sudah tercatat di doc 48.

3. **Fix #2 (select tanpa panah).** Root cause: semua `<select>` pakai
   `appearance-none` (menghapus panah native) tanpa ikon pengganti, sehingga
   tampak seperti input teks. Solusi: bungkus tiap select dengan container
   `relative`, tambahkan `pe-10` pada select, dan overlay `ChevronDownIcon`
   (`absolute inset-y-0 end-3 my-auto`, `pointer-events-none`, RTL-aware pakai
   `end-*`). Diterapkan ke select: Category (grup produk), Product (grup,
   kategori, uom, supplier, tipe produk), dan User (role).

4. **Fix #3 (checkbox → toggle switch).** Dibuat komponen bersama
   `src/components/ui/ToggleSwitch.vue` (v-model boolean, dark mode, label
   opsional, RTL-aware, role="switch"). Semua `<input type="checkbox">` di form
   ERP diganti ToggleSwitch: toggle "Aktif" (UOM, Supplier, Product-Group,
   Category, Product, User), "Lacak batch" (Product), dan daftar akses outlet di
   User (dari checkbox list menjadi baris label + ToggleSwitch). Checkbox yang
   tersisa hanya di file demo template TailAdmin (`forms/FormElements/*`,
   `profile/Security.vue`) — di luar scope form ERP, tidak disentuh.

Standar UI ini juga sudah didokumentasikan di `knowledge-base/48.tailadmin-frontend-backlog.md`
(dibuat sesi sebelumnya): tombol aksi icon-only, select wajib punya chevron,
gunakan toggle switch bukan checkbox, modal transparan, catatan port backend 5000,
dan status QA otomatis dijeda.

## [12:47] Halaman CRUD Outlet (frontend-tailadmin) — frontend-dev

Diminta project-manager membangun halaman CRUD Outlet di `frontend-tailadmin/`
(Vue 3 + Vite + Tailwind v4), meniru pola modul Supplier 1:1. Backend Outlet
sudah ada & lengkap — tidak disentuh.

Yang saya kerjakan:
- Mempelajari modul Supplier sebagai referensi: service, composable `useSuppliers`,
  view `SupplierList.vue`, dan komponen `SupplierTable/FormModal/DeleteModal`.
  Memastikan tidak ada barrel `index.ts` di folder supplier, jadi outlet juga tidak
  dibuatkan `index.ts`.
- UPGRADE `outlet.service.ts` dari read-only menjadi CRUD penuh: menambah field
  `address/phone/createdAt/updatedAt` di interface `Outlet`, tipe `CreateOutletPayload`
  & `UpdateOutletPayload`, serta method `create/update/remove`. Method `list` tetap
  dipertahankan kompatibel (dipakai modul Users untuk picker outlet); perubahan
  interface hanya menambah field opsional sehingga tidak breaking.
- Membuat `useOutlets.ts` (tiru `useSuppliers`): state list, pagination, debounced
  search, filter, create/update/remove; error 409 saat delete di-surface via
  `toMessage` ke banner error di delete modal.
- Membuat view `OutletList.vue` + komponen `OutletTable.vue`, `OutletFormModal.vue`,
  `OutletDeleteModal.vue`.

Keputusan penting:
- `code` di-generate backend → TIDAK ada input `code` di form create; ditampilkan
  sebagai kolom read-only pertama di tabel dan teks read-only di modal edit.
- UI mengikuti standar terbaru: aksi tabel icon-only (Pencil/Trash2), modal backdrop
  transparan (light dim + blur), toggle "Aktif" pakai `ToggleSwitch` (bukan checkbox).
  Outlet tidak punya `<select>`, jadi aturan overlay chevron tidak diperlukan.
- Sidebar: Outlet diletakkan di ATAS grup Master Data (sebelum Units of Measure)
  karena master paling fundamental; ikon `BoxCubeIcon` (sudah dipakai modul lain).
- Rute `/master/outlets` name `Outlets` meta permission `outlet.read`; gate manage
  pakai `outlet.manage`.
