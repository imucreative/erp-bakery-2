## [04:49] Melengkapi semantic variants BaseButton

Atas masukan User, kontrak `BaseButton` diperluas agar mencakup seluruh semantic color
token yang tersedia di frontend:

- `success` menggunakan token `success-*`.
- `info` menggunakan token `blue-light-*` sebagai palette informasi.
- `warning` menggunakan token `warning-*`.
- `danger` tetap menggunakan token `error-*`.

`primary` tetap menggunakan token `brand-*`, sedangkan `outline` tetap menjadi varian
non-solid. Varian `secondary` atau `ghost` tidak ditambahkan karena belum memiliki
token/pola standar yang berbeda dari `outline`. Perubahan menunggu quality check dan
pengujian manual bersama batch Category yang masih uncommitted.
