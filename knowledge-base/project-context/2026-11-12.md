## Migrasi base UI component ke Reka UI

- `BaseCheckbox` → `CheckboxRoot` + `CheckboxIndicator` (ikon `Check`); utility
  `.checkbox` disesuaikan untuk `data-state`.
- `BaseModal` → `DialogRoot`/`DialogPortal`/`DialogOverlay`/`DialogContent`.
  Mendapat focus trap, scroll lock, Esc/outside-click yang dikontrol
  `dismissible`, dengan API (`open`, `size`, `placement`, `scrollable`) tetap.
- `ToggleSwitch` (dipakai `BaseToggle`) → `SwitchRoot` + `SwitchThumb`.
- `BaseFormField` → `Label` dari Reka.
- `BaseSelect` → `SelectRoot`/`SelectTrigger`/`SelectContent` (portal + popper)
  /`SelectItem`. Karena `SelectItem` Reka menolak nilai string kosong, opsi
  `value: ''` (mis. "Semua Outlet") dipetakan ke sentinel internal lalu
  diterjemahkan kembali saat emit, sehingga API pemanggil tidak berubah.
- Bugfix setelah uji UI: `DialogPortal` Reka selalu merender slot-nya, sehingga
  wrapper `fixed inset-0 z-99999` pada `BaseModal` ikut ter-render saat modal
  tertutup dan memblokir seluruh klik (tombol/input/menu terasa hang). Wrapper
  sekarang memakai `v-if="props.open"`; `SelectContent` tidak bermasalah karena
  saat tertutup dirender ke DocumentFragment yang tidak menempel di DOM.
- Tidak dimigrasikan: `EntityCombobox` (logika server-search, portal, scroll,
  dan ARIA sudah custom; kandidat migrasi Reka Combobox terpisah),
  `BaseInput`/`BaseTextarea`/`BaseFileButton` (kontrol native tidak punya
  primitive Reka), serta `BaseButton`/`BaseTable`/`BaseAlert`/`Badge`
  (presentational/semantik).
- Catatan: `components/ui/Modal.vue` dan `components/ui/Button.vue` tidak
  dipakai lagi (kandidat penghapusan setelah konfirmasi).
