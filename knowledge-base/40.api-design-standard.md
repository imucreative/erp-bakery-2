# 40. API Design Standard

This document establishes the API contract conventions, query formats, and payload structures for all REST endpoints in the Bakery ERP.

---

## 1. REST Conventions & URIs

- **Case Style**: Lowercase plural for resource names (e.g. `/api/v1/purchase-orders`).
- **Endpoint Structure**:
  - `GET /api/v1/<resources>` -> List paginated items.
  - `GET /api/v1/<resources>/:id` -> Retrieve specific details.
  - `POST /api/v1/<resources>` -> Create a new record (starts in Draft).
  - `PUT /api/v1/<resources>/:id` -> Fully replace/update a record.
  - `PATCH /api/v1/<resources>/:id/status` -> Update status/trigger transition.
  - `DELETE /api/v1/<resources>/:id` -> Soft-delete/deactivate a record.

---

## 2. Response Contracts

### A. List Data Payload
```json
{
  "success": true,
  "data": [
    {
      "id": "782ca447-0b1e-4509-b4cc-924f794b1509",
      "prNumber": "PR-2026-000001",
      "status": "SUBMITTED"
    }
  ],
  "meta": {
    "page": 1,
    "limit": 10,
    "total": 1
  }
}
```

### B. Single Resource Detail Payload
```json
{
  "success": true,
  "data": {
    "id": "782ca447-0b1e-4509-b4cc-924f794b1509",
    "prNumber": "PR-2026-000001",
    "expectedDate": "2026-07-20T00:00:00.000Z",
    "status": "SUBMITTED",
    "items": [
      {
        "id": "122ca447-0b1e-4509-b4cc-924f794b1502",
        "productId": "992ca447-0b1e-4509-b4cc-924f794b1500",
        "quantity": 10
      }
    ]
  }
}
```

### C. Error Payload
```json
{
  "success": false,
  "message": "Validation Failed",
  "errors": [
    {
      "field": "expectedDate",
      "message": "Expected date must be in the future"
    }
  ]
}
```

---

## 3. Query Parameter Handling

List endpoints must support standard query parameters:

- **Pagination**: Mandatory `page` (default `1`) and `limit` (default `10`).
- **Sorting**: Standardized `sortBy` (field name, default `createdAt`) and `sortOrder` (`asc` | `desc`, default `desc`).
- **Search**: Generic search key `search=keyword` querying multiple indexed columns (e.g. searching invoice number, customer name, vendor name).
- **Filtering**: Direct key-value match filters (e.g., `?status=DRAFT&locationId=uuid`).
