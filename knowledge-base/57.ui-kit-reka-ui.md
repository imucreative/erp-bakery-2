# 57. UI Kit — Reka UI Implementation Standard

**Status:** ACTIVE (2026-11-12)
**Scope:** `frontend-tailadmin/`
**Package:** `reka-ui` `^2.11.0` (sudah terpasang)

---

## 1. Prinsip Wajib

1. **Reka UI adalah dasar interaksi UI sekarang.** Setiap base component
   interaktif yang punya padanan di Reka UI WAJIB memakai primitive Reka UI di
   balik wrapper `src/components/ui/Base*.vue`.
2. **Feature code memakai wrapper proyek**, bukan mengimpor `reka-ui` langsung.
   Jika sebuah primitive belum punya wrapper, buat/ubah wrapper `Base*.vue`
   terlebih dahulu agar seluruh aplikasi memakai perilaku yang sama.
3. **API wrapper tidak boleh berubah tanpa migrasi call-site.** Pertahankan
   `v-model`, props, emits, dan attrs yang sudah dipakai fitur.
4. **Jangan menambah package baru tanpa persetujuan user.** Reka UI sudah
   terpasang; tidak perlu instalasi ulang.
5. **Styling tetap lewat Tailwind v4 + token proyek** (`ui.css`, `theme.css`),
   wajib dark mode dan properti logis RTL (`ps/pe/ms/me/start/end`).

auto-submit. Kode recovery (alfanumerik) tetap memakai `BaseInput`, bukan
`BasePinInput`.

## 4. Aturan Implementasi / Migrasi

1. **Satu komponen per perubahan** — jangan mencampur beberapa migrasi besar
   dalam satu commit tanpa alasan kuat.
2. **Audit call-site dulu**: hitung pemakaian, props, event, dan attr yang
   benar-benar dipakai. Wrapper harus kompatibel.
3. **Pertahankan perilaku**: placeholder, disabled, error/aria, `v-model`,
   keyboard, click-outside, dan ukuran visual.
4. **Styling** memakai `@utility` di `src/assets/styles/ui.css` bila style itu
   dipakai berulang; jangan menulis hex color.
5. **Verifikasi wajib**:
   ```bash
   npm run type-check
   npx eslint <file-yang-diubah>
   npm run build-only
   ```
6. **Uji manual**: buka/tutup, keyboard (Tab/Space/Enter/Esc), klik luar,
   opsi kosong, dark mode, RTL, dan viewport mobile.
7. **Catat ke project-context** setelah selesai (lihat aturan log harian).

## 5. Jebakan yang Sudah Ditemukan

1. **`SelectItem` menolak `value=""`.**
   Reka memakai string kosong untuk "clear selection". Opsi bisnis seperti
   "Semua Outlet" harus dipetakan ke sentinel internal di `BaseSelect` lalu
   diterjemahkan kembali saat `update:modelValue`.
2. **`DialogPortal` selalu merender slot-nya.**
   Wrapper `fixed inset-0` di dalam portal wajib memakai `v-if="open"`;
   jika tidak, wrapper menutupi seluruh layar meski modal tertutup dan semua
   klik mati (pernah terjadi pada `BaseModal`).
3. **`SelectContent` saat tertutup** dirender ke `DocumentFragment` (tidak
   menempel di DOM), jadi tidak memblokir klik. Jangan menambahkan wrapper
   full-screen sendiri di dalam portal select.
4. **Pointer-events & scroll lock** diatur Reka lewat `DismissableLayer`.
   Jangan menimpa `pointer-events` body secara manual.
5. **Nested layer** (Select di dalam Dialog) sudah ditangani Reka; pastikan
   z-index `SelectContent` lebih tinggi dari modal (dipakai `z-[100000]`).
6. **Placeholder `SelectValue`** memakai atribut `data-placeholder`; styling
   placeholder memakai varian `data-[placeholder]:...`.
