# 38. Form Standard

This document defines the structural patterns, validation rules, state management, and lifecycle events for all data input forms in the Bakery ERP dashboard.

---

## 1. Core Technologies
- **Form State Manager**: `react-hook-form`
- **Validation Resolver**: `@hookform/resolvers/zod`
- **Component Wrapper**: `ERPForm`, `ERPFormSection`, `ERPFormActions`

---

## 2. Standard Form Component Blueprint

Every input form in features dashboard modules must be structured as a reusable client component wrapping `ERPForm`:

```typescript
'use client';

import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';
import { createPurchaseRequestSchema, type CreatePurchaseRequestInput } from '../schemas/purchase-request.schema';
import { ERPForm, ERPFormSection, ERPFormActions, ERPInput, ERPSelect } from '@/components/erp';
import { useCreatePurchaseRequest } from '../hooks/use-create-purchase-request';

interface PurchaseRequestFormProps {
  onSuccess: () => void;
  onCancel: () => void;
}

export function PurchaseRequestForm({ onSuccess, onCancel }: PurchaseRequestFormProps) {
  const createMutation = useCreatePurchaseRequest();

  const form = useForm<CreatePurchaseRequestInput>({
    resolver: zodResolver(createPurchaseRequestSchema),
    defaultValues: {
      destinationLocationId: '',
      expectedDate: new Date(),
      items: [{ productId: '', quantity: 1, uomId: '', estimatedPrice: 0 }]
    }
  });

  const onSubmit = (data: CreatePurchaseRequestInput) => {
    createMutation.mutate(data, {
      onSuccess: () => {
        form.reset();
        onSuccess();
      }
    });
  };

  return (
    <ERPForm onSubmit={form.handleSubmit(onSubmit)}>
      <ERPFormSection title="General Information">
        <ERPSelect
          label="Destination Location"
          {...form.register('destinationLocationId')}
          error={form.formState.errors.destinationLocationId?.message}
          options={locationOptions}
        />
        <ERPInput
          label="Expected Arrival Date"
          type="date"
          {...form.register('expectedDate')}
          error={form.formState.errors.expectedDate?.message}
        />
      </ERPFormSection>

      <ERPFormActions 
        isSubmitting={form.formState.isSubmitting} 
        onCancel={onCancel}
      />
    </ERPForm>
  );
}
```

## 3. Dynamic Sub-Forms (Line Items)

For complex multi-line forms (such as adding products inside a Purchase Request), utilize `useFieldArray` from `react-hook-form`:

```typescript
import { useFieldArray } from 'react-hook-form';

// Inside component:
const { fields, append, remove } = useFieldArray({
  control: form.control,
  name: "items"
});

// Inside render JSX:
{fields.map((field, index) => (
  <div key={field.id} className="grid grid-cols-4 gap-2">
    <ERPSelect
      {...form.register(`items.${index}.productId` as const)}
      error={form.formState.errors.items?.[index]?.productId?.message}
    />
    <ERPInput
      type="number"
      {...form.register(`items.${index}.quantity` as const, { valueAsNumber: true })}
      error={form.formState.errors.items?.[index]?.quantity?.message}
    />
    <button type="button" onClick={() => remove(index)}>Remove</button>
  </div>
))}
<button type="button" onClick={() => append({ productId: '', quantity: 1, uomId: '', estimatedPrice: 0 })}>
  Add Item
</button>
```

## 4. Dialog Flow Integration
- **State Ownership**: The open/close state of forms dialogs must reside in the parent `page.tsx` component.
- **Form Resetting**: Forms must reset their internal values to defaults whenever the dialog modal transitions to `closed`.
- **Dirty Checks**: If a user tries to close a modal when `formState.isDirty` is true, display a confirmation warning to prevent accidental data loss.
